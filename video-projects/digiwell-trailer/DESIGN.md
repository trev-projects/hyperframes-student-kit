# Digiwell — Trailer Design Reference

> Brand tokens are inherited from `../digiwell-promo/DESIGN.md` — that's the source of truth. This file only notes what's specific to the **trailer** variant.

## What's the same

- Canvas `#07080c` near-black
- Amber Primary `#f9a72c` · Amber Hot `#ff8a2a` · Amber Soft `#ffd480`
- Growth Teal `#3de0a6` (counters + outcome stats only)
- Warm-chrome gradient `#fff → #f7d99a → #f9a72c` on hero type
- Inter 500–800 + JetBrains Mono 600
- Amber halo on emphasis: `text-shadow: 0 0 24px rgba(249,167,44,.6), 0 0 60px rgba(249,167,44,.25)`
- Particle-trail Canvas 2D recipe (60 amber dots, seeded PRNG, conic drift) — used on Beats 0 + 4
- Amber whip-streak between beats (`linear-gradient(90deg, transparent, rgba(249,167,44,.9), transparent)`, blurred 10px, 0.35s `power3.in`)

## What's different from the promo

- **No VO.** Visuals + music carry the whole story. Pacing on each beat is held ~1.5–2× longer than the promo's beats so muted viewers can read.
- **Evergreen positioning, not feature pitch.** No "47% open rate" as a standalone proof beat — the result number is fused into the service card alongside it.
- **5 beats not 7.** Compressed structure: cold open → thesis → fused services+results → bridge → CTA.
- **No "Free Audit" pulled into Beat 6** — the audit pill lives only in the CTA outro.

## Audio

- `assets/music.wav` — generated by `scripts/make-music.py`. Warm C-major pad + 90 BPM ghost kick + amber-shimmer plucks at beat seams + filtered noise sweep that swells around 18s. Different palette from the RVL trailer's bed.
- Loudnorm to -14 LUFS in post (ffmpeg).
